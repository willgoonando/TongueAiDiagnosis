# 13 — 调用全链路一图流（文本版）

## 从上传到诊断建议的完整路径

```
用户上传图片
    │
    ▼
┌────────────────────────────────────────────────────────────┐
│  前端 Vue3                                                  │
│  ChatHome.vue                                               │
│    sendCoatingImage(file)                                   │
│      → POST /api/model/session (FormData: file_data+input) │
│      → 等待 SSE 流式返回                                    │
│      → ChatMain.vue 逐 token 展示回复                       │
└──────────────────────────┬─────────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────────┐
│  FastAPI 后端                                                │
│  routes/model_api.py                                        │
│    upload()                                                  │
│      → analyse_tongue_image()  [services/tongue_service.py] │
│        │  ① 保存图片到磁盘                                  │
│        │  ② 写数据库记录 (state=0)                          │
│        │  ③ TonguePredictor.predict() 塞入队列              │
│        │  ④ 轮询等待数据库 state 变 1                       │
│        │                                                    │
│        ▼ (异步线程)                                          │
│    ┌───────────────────────────────┐                        │
│    │  AI 推理线程 (predict.py)      │                        │
│    │  main() 死循环消费队列         │                        │
│    │    ↓                           │                        │
│    │  __predict()                   │                        │
│    │    ├─ YOLOv5 舌体定位          │                        │
│    │    │   weights/yolov5.pt       │                        │
│    │    ├─ SAM 精细分割              │                        │
│    │    │   weights/sam_vit_b.pth   │                        │
│    │    ├─ 舌体裁剪                  │                        │
│    │    ├─ 4×ResNet50 分类          │                        │
│    │    │   weights/*.pth ×4        │                        │
│    │    └─ 回调写数据库 (state=1)    │                        │
│    └───────────────────────────────┘                        │
│        │                                                    │
│        ▼ (轮询完成)                                         │
│     ⑤ 格式化特征: "舌色：淡红舌；苔色：白苔..."              │
│     ⑥ 创建对话记录                                          │
│     ⑦ 调 Ollama → Deepseek-R1:8b → SSE 流式                │
│        [routes/ollama_used.py]                              │
└──────────────────────────┬─────────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────────┐
│  前端 Vue3 (SSE 接收)                                       │
│  ChatMain.vue                                               │
│    streamResponse()                                          │
│      → 逐 token 解析 JSON                                   │
│      → 逐字追加到 AI 回复区域                                │
│      → 用户看到完整诊断建议                                  │
└────────────────────────────────────────────────────────────┘
```

## 数据流（路径清晰版）

```
上传图片 (用户)
  │  POST /api/model/session (FormData)
  ▼
tongue_service.py 保存到磁盘
  │  img_src = "tongue/{record_id}.jpg"
  ▼
predict.py 推理队列收到任务
  │  queue.put((img, record_id, fun))
  ▼
main() 线程消费
  │  queue.get() → __predict()
  ▼
YOLOv5 推理 → 边界框 (x1,y1,x2,y2,conf)
  ▼
SAM 推理 → 像素级掩码 best_mask
  ▼
裁剪 + 预处理 → 舌体图片 (背景黑色)
  ▼
ResNet50 ×4 → [舌色, 苔色, 厚薄, 腐腻]
  ▼
回调 fun() → TongueAnalysis表 state=0→1
  ▼
tongue_service.py 轮询检测到完成
  ▼
model_api.py 格式化特征文字
  ▼
Ollama (Deepseek-R1) 生成诊断建议
  ▼
SSE 流式返回给前端
  ▼
前端逐 token 渲染就是老中医诊断
```

## 文件路径一览

| 步骤 | 文件 | 关键函数 |
|------|------|---------|
| 前端上传 | `frontend/src/views/ChatHome.vue` | `sendCoatingImage()` |

| SAM 分割 | `application/net/predict.py` | SAM predictor |
| ResNet 分类 | `application/net/model/resnet.py` | `predict()` |
| 注意力模块 | `application/net/model/attention/*.py` | CBAM/SE/ECA |
| LLM 生成 | `application/routes/ollama_used.py` | `call_ollama_stream()` |
| 数据库操作 | `application/orm/crud/tongue_analysis.py` | CRUD 函数 |
| OCR 识别 | `application/services/ocr_service.py` | `recognize()` |
| 流水线 API | `application/routes/pipeline_api.py` | `get_pipeline()` |
| 流水线展示 | `frontend/src/views/PipelineDemo.vue` | 时间线组件 |
| 入口 | `run.py` | 启动 FastAPI + 推理线程 |
