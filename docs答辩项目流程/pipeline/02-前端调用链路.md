# 02 — 前端调用链路

用户操作 → 前端处理 → 后端路由

## 流程图

```
用户点击上传 ──► UploadPicture.vue ──► ChatHome.vue
                   读取文件                │
                   转为Base64              │
                                          ▼
                                sendCoatingImage(file)
                                      │
                                      │ 构造 FormData:
                                      │ file_data, user_input, name
                                      │
                                      ▼
                           POST /api/model/session
                           (fetch, 无Axios拦截器)
                                      │
                                      ▼
                           SSE 流式读取响应
                           streamResponseWithSessionId()
                                      │
                                      ▼
                       ChatMain.vue 逐 token 展示
```

## 关键文件

### `ChatHome.vue` — 主页面
- `sendCoatingImage(file)` 第 240 行：上传舌象图片创建新会话
- `streamResponseWithSessionId()` 第 380 行：流式读取后端返回

### `ChatMain.vue` — 聊天区域
- 展示用户消息（图片 + 文字）
- 展示 AI 回复（流式逐字渲染）
- 加载历史记录

### `UploadPicture.vue` — 上传组件
- 拖拽/点击上传
- 读取文件转为 Base64
- 通过 emit 传给父组件

```javascript
const sendCoatingImage = async (file) => {

  formData.append('user_input', '请分析这张舌象图片')
  formData.append('name', `舌诊-${new Date().toLocaleString()}`)

  const response = await fetch(`/api/model/session`, {
    method: 'POST',
    headers: { 'Authorization': `Bearer ${token}` },
    body: formData
  })

}
```

## 配置

`frontend/src/config/config.js`:
```javascript
ServerUrl: 'http://localhost:5000'   // 后端地址
```

`main.js` 中 Axios 配置:
```javascript
axios.defaults.baseURL = ServerUrl + '/api'  // 所有请求加 /api 前缀
```
