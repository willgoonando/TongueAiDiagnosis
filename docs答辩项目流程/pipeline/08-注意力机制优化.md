# 08 — 注意力机制优化

**所在目录**: `application/net/model/attention/`

这是独立于单纯调包之外的工作量——你**自己实现了多种注意力机制**，并用 forward hook 注入到 YOLOv5 中。

## 实现的三种注意力机制

### CBAM（Convolutional Block Attention Module）
**文件**: `attention/cbam.py`

串联通道注意力 + 空间注意力：
```python
class CBAM(nn.Module):
    def forward(self, x):
        x = self.channel_attention(x) * x  # 先通道注意力
        x = self.spatial_attention(x) * x  # 再空间注意力
        return x
```

- **通道注意力**: 关注"什么"特征重要（颜色、纹理等）
- **空间注意力**: 关注"哪里"重要（舌头的哪个区域）
- 两者互补，比单用其中一种效果好

### SE（Squeeze-and-Excitation）
**文件**: `attention/se.py`

只做通道注意力：
```python
class SE(nn.Module):
    def forward(self, x):
        # Squeeze: 全局平均池化
        # Excitation: 两个全连接层学习通道权重
        # Scale: 加权原始特征
        return self.scale(x, self.excitation(self.squeeze(x)))
```

计算量小、效果好，已嵌入 ResNet50 分类器中使用。

### ECA（Efficient Channel Attention）
**文件**: `attention/eca.py`

SE 的改进版，用 1D 卷积代替全连接层：
```python
class ECA(nn.Module):
    def forward(self, x):
        # 用 1D 卷积代替 SE 的两个 FC 层
        # 更轻量、参数更少
        return x * self.conv1d(...)
```

参数量远小于 SE，适合对推理速度要求高的场景。

## 如何注入 YOLOv5

你用了 **forward hook** 机制——这是 Python 的高级用法，不改 YOLOv5 源码就把注意力模块插入：

```python
# train_yolov5_attention.py 中的关键逻辑
def add_attention_hook(model, attention_module='CBAM'):
    for name, module in model.named_modules():
        if isinstance(module, nn.Conv2d):  # 在卷积层后注入
            module.register_forward_hook(attention_hook)
```

**为什么要用 forward hook 而不是直接改源码？**
- 不破坏 YOLOv5 的原有结构
- 可以随时切换不同的注意力模块
- 避免和未来版本冲突
