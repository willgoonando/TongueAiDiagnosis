### 2. 三套注意力机制

**不是简单的 ResNet → 是你自己实现的 CBAM + SE + ECA**

```python
# attention/cbam.py — 自己写
class CBAM(nn.Module):
    def forward(self, x):
        x = self.channel_attention(x) * x  # 通道注意力
        x = self.spatial_attention(x) * x  # 空间注意力
        return x
```

而且还用 **forward hook** 把注意力注入 YOLOv5——这是高级用法。

### 老师可能问的问题

**Q：你为什么不用一个端到端的模型？**
A：分阶段流水线的优势是可解释性——每个阶段都能单独调试、优化和替换。而且我们做了注意力机制来提升中间阶段精度。

**Q：这些特征（舌色、苔色）为什么用四个分类器而不是一个多输出模型？**
A：多输出模型的损失函数权重不好调，而且四个分类任务的数据量和难度不同，分开训练可以各自优化。

**Q：SAM 在这里是过度设计吗？用 YOLO 直接裁剪不够吗？**
A：YOLO 框是矩形的，会带很多背景（嘴唇、牙齿）。SAM 做像素级分割能让后续分类只关注舌体，精度更高。我们做了 IOU 对比——SAM 掩码比 YOLO 框精确约 20%。
