# 01 — 项目架构概览

## 🏗️ 整体架构

前端 Vue3  →  FastAPI 后端  →  AI推理引擎  →  Ollama本地LLM
  用户界面       REST API         YOLO+SAM+ResNet    Deepseek-R1

## 🔧 技术栈

| 层 | 技术 |
|---|---|
| 前端框架 | Vue 3 + Vite |
| UI 组件库 | Element Plus |
| HTTP 客户端 | Axios |
| 后端框架 | FastAPI (Python) |
| 数据库 | SQLite + SQLAlchemy |
| 目标检测 | YOLOv5 (Ultralytics) |
| 语义分割 | SAM (Meta) |
| 图像分类 | ResNet50 (自定义 ×4) |
| 注意力机制 | CBAM / SE / ECA |
| OCR | EasyOCR (离线) |
| 本地LLM | Ollama + Deepseek-R1-8B |
| 流式响应 | SSE (Server-Sent Events) |
| 认证 | JWT |
